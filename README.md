# KFPL Football Manager 2026

KFPL 풋볼 매니저의 **설치 파일·업데이트·이용 안내를 제공하는 배포 저장소**입니다.

현재 Windows PC판 테스트를 준비하고 있습니다. 모바일 앱 전환은 후속 개발 대상입니다.

## 다운로드

[Releases에서 배포 버전 확인하기](https://github.com/YukinositaRenji/KFPL/releases)

설치 파일은 Releases에 게시합니다. 릴리스가 표시되지 않으면 아직 공개 배포 전입니다. 저장소의 **Code → Download ZIP은 게임 설치 파일이 아닙니다.**

## PC판에서 준비한 기능

- 인터넷 없이 커리어 생성과 플레이
- PC에 진행 상황 저장, 정상 종료 시 저장과 백업
- 경기 도중 종료한 뒤 일시정지 상태로 이어하기
- 기존 웹·PC 커리어 백업을 별도 커리어로 가져오기
- 이전 시즌 경기 기록 보관

웹 커리어와 PC 커리어는 자동 동기화되지 않습니다. 기존 웹 진행을 옮기려면 백업 파일을 내보내 가져와 주세요.

## 현재 테스트판 상태

0.1.0은 사전 검증용 테스트판입니다. 저장·복원 자동검사를 통과했으며, Windows 실기기 설치·게임 화면 조작·업데이트 설치 확인은 남아 있습니다. Windows 코드 서명과 자동 패치 배포 연결도 준비 중입니다.

자동 패치가 지원되는 버전은 해당 릴리스 공지에 명시합니다. **0.1.0 테스트판의 자동 패치는 아직 활성화되어 있지 않습니다.**
