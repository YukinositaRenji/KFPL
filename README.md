# KFPL Football Manager 2026

KFPL 풋볼 매니저의 **설치 파일·업데이트·이용 안내를 제공하는 배포 저장소**입니다.

Windows PC 테스트판 0.2.1을 배포했습니다. 테스트 자동 업데이트를 지원하며 모바일 앱 전환은 후속 개발 대상입니다.

## 다운로드

[0.2.1 테스트판 다운로드](https://github.com/YukinositaRenji/KFPL/releases/tag/pc-test)

설치 파일은 Releases에 게시합니다. 릴리스가 표시되지 않으면 아직 공개 배포 전입니다. 저장소의 **Code → Download ZIP은 게임 설치 파일이 아닙니다.**

## PC판에서 준비한 기능

- 소속 선수 2~4명 비교, 선수단 검색·필터·정렬 유지
- 감독 홈 메시지의 해당 본문 바로 열기와 수신함 방향키 이동
- 작은 창과 접힌 사이드바에 맞춘 전술 배치

- FM 방식의 왼쪽 구단 메뉴, 상단 통합 검색·날짜·진행, 중앙 관리 화면
- 감독 홈에서 다음 경기·일정·수신함·순위·선수단 상태 확인
- 선수·구단·메뉴 검색과 저장·화면 이동 단축키
- 환경설정에서 테마와 화면 밀도 조절
- 외부 구단 로고 31종을 설치판에 포함해 인터넷 없이 표시

- 인터넷 없이 커리어 생성과 플레이
- PC에 진행 상황 저장, 정상 종료 시 저장과 백업
- 경기 도중 종료한 뒤 일시정지 상태로 이어하기
- 기존 웹·PC 커리어 백업을 별도 커리어로 가져오기
- 이전 시즌 경기 기록 보관

웹 커리어와 PC 커리어는 자동 동기화되지 않습니다. 기존 웹 진행을 옮기려면 백업 파일을 내보내 가져와 주세요.

## 현재 테스트판 상태

0.2.1은 Windows 배포자 서명이 없는 테스트판이며 테스트 자동 업데이트가 연결되어 있습니다. 시작 후 새 버전을 확인하고 백그라운드에서 다운로드합니다. 정상 종료 시 저장·전체 커리어 백업을 마친 뒤 설치합니다.

**0.1.0·0.1.1 사용자는 0.2.1을 한 번 직접 설치해야 합니다.** 먼저 게임 내 백업을 만들고 정상 종료한 뒤 같은 위치에 설치하세요.

0.1.3에서 수정한 설치·삭제 복구 기능을 유지합니다. 0.1.0~0.1.2 제거 프로그램의 NSIS 무결성 오류를 복구합니다. 기존 제어판 삭제가 실패해도 0.2.1 설치파일이 알려진 오류 파일을 먼저 복구합니다. 이전 버전 설치파일은 사용하지 마세요.

Windows CI에서 타입 검사·빌드·자동 테스트 20개, 설치·손상된 제거 파일 복구 재설치·삭제·재설치를 통과했고 저장 폴더의 표식 파일 보존을 확인했습니다. Windows에서 로고·주요 화면·검색·환경설정과 선수 데이터 유지를 추가 검사했습니다. 실제 사용자 PC에서의 버전 간 자동 업데이트 전체 과정은 추가 확인이 필요합니다.
