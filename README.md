# KFPL Football Manager 2026

KFPL 풋볼 매니저의 **설치 파일·업데이트·이용 안내를 제공하는 배포 저장소**입니다.

Windows PC 테스트판 0.1.2를 배포했습니다. 테스트 자동 업데이트를 지원하며 모바일 앱 전환은 후속 개발 대상입니다.

## 다운로드

[0.1.2 테스트판 다운로드](https://github.com/YukinositaRenji/KFPL/releases/tag/pc-test)

설치 파일은 Releases에 게시합니다. 릴리스가 표시되지 않으면 아직 공개 배포 전입니다. 저장소의 **Code → Download ZIP은 게임 설치 파일이 아닙니다.**

## PC판에서 준비한 기능

- 인터넷 없이 커리어 생성과 플레이
- PC에 진행 상황 저장, 정상 종료 시 저장과 백업
- 경기 도중 종료한 뒤 일시정지 상태로 이어하기
- 기존 웹·PC 커리어 백업을 별도 커리어로 가져오기
- 이전 시즌 경기 기록 보관

웹 커리어와 PC 커리어는 자동 동기화되지 않습니다. 기존 웹 진행을 옮기려면 백업 파일을 내보내 가져와 주세요.

## 현재 테스트판 상태

0.1.2는 Windows 배포자 서명이 없는 테스트판이며 테스트 자동 업데이트가 연결되어 있습니다. 시작 후 새 버전을 확인하고 백그라운드에서 다운로드합니다. 정상 종료 시 저장·전체 커리어 백업을 마친 뒤 설치합니다.

**0.1.0·0.1.1 사용자는 0.1.2를 한 번 직접 설치해야 합니다.** 먼저 게임 내 백업을 만들고 정상 종료한 뒤 같은 위치에 설치하세요.

타입 검사·빌드·자동 테스트 18개와 배포 파일 해시를 확인했습니다. Windows 실기기 설치·화면 조작·버전 간 자동 설치는 추가 확인이 필요합니다.
