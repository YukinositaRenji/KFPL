# 설치와 시작

## Windows 64비트 테스트판 0.2.1

1. 기존 게임을 저장하고 정상 종료합니다. 열려 있는 이전 설치·삭제 창도 닫아 주세요.
2. [0.2.1 테스트 배포](https://github.com/YukinositaRenji/KFPL/releases/tag/pc-test)에서 `KFPL-FM-2026-Setup-0.2.1-x64.exe`를 받습니다.
3. 기존 게임이 있으면 같은 설치 위치를 선택합니다. **제어판에서 먼저 삭제할 필요가 없습니다.**
4. 설치 후 게임을 실행하고 기존 커리어를 확인합니다.

0.1.0~0.1.2에 포함된 제거 프로그램의 무결성 오류 때문에 제어판 삭제가 실패하거나 재설치 때 게임을 닫으라는 메시지가 반복될 수 있습니다. 0.2.1은 확인된 오류 파일을 백업하고 정상 제거 프로그램으로 교체한 뒤 설치합니다. 게임 저장 데이터는 변경하지 않습니다.

## 설치하지 않고 삭제만 하려면

게임과 이전 설치·삭제 창을 닫은 뒤 릴리스의 `KFPL-Repair.exe`를 실행하세요. 복구 완료 안내 후 제어판에서 삭제를 다시 실행합니다. 복구 대상이 없다는 안내나 오류가 나오면 그 내용을 제보해 주세요.

저장 데이터는 기본적으로 `%APPDATA%\KFPL Football Manager 2026\saves`에 남습니다. 게임이 종료된 상태에서 폴더를 복사해 별도 보관할 수 있습니다. 이 폴더를 수동 삭제하지 마세요.

## 새 PC 화면

- 선수단에서 2~4명의 체크박스를 선택한 뒤 선수 비교를 누릅니다.
- 같은 커리어에서 메뉴를 오가면 검색·필터·정렬·선택을 유지합니다. 로비 이동·재실행 시 초기화됩니다.
- 수신함 메시지 목록에서 ↑·↓·Home·End로 이동할 수 있습니다.

- 왼쪽 메뉴에서 선수단·전술·훈련·의료·재정 등으로 바로 이동합니다.
- Ctrl+K: 선수·구단·메뉴 검색 / Ctrl+S: 저장 / Alt+←·→: 이전·다음 화면
- 환경설정 → 표시·진행에서 테마와 표준·촘촘한 화면 밀도를 선택합니다.
- 환경설정 → 데이터 또는 하단 PC 관리에서 백업·저장 폴더·업데이트를 관리합니다.
- 구단 로고는 설치판에 포함되며 인터넷 연결 없이 표시됩니다.
- 선수 명단·능력치·기존 커리어의 저장 형식은 변경하지 않았습니다.

## 테스트판 안내

- Windows 배포자 서명이 없는 테스트판입니다.
- 0.1.0·0.1.1은 처음 한 번 0.2.1을 직접 설치해야 합니다. 0.1.2부터는 테스트 자동 업데이트 주소가 연결되어 있습니다.
- Windows CI의 설치·복구 재설치·삭제·재설치 검사를 통과했습니다. 실제 사용자 PC의 버전 간 자동 업데이트 전체 과정까지 확인한 것은 아닙니다.
- 웹 진행은 자동 동기화되지 않습니다. 게임의 **웹·PC 백업 가져오기**를 사용하세요.

저장소의 **Code → Download ZIP은 게임 설치파일이 아닙니다.**
