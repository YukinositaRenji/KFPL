# 설치와 시작

## Windows PC판

1. [Releases](https://github.com/YukinositaRenji/KFPL/releases)에서 원하는 버전의 공지를 확인합니다.
2. `KFPL-FM-2026-Setup-<버전>-x64.exe` 설치 파일을 받습니다. ZIP으로 제공된 경우 먼저 압축을 풉니다.
3. 설치 프로그램의 안내를 따라 설치한 뒤 **KFPL FM 2026**을 실행합니다.
4. 새 커리어를 만들거나 **웹·PC 백업 가져오기**로 기존 진행을 옮깁니다.

게시된 릴리스가 없으면 아직 다운로드용 공개 배포 전입니다. Android·macOS·Linux용 파일과 혼동하지 마세요. 현재 이 안내의 대상은 Windows 64비트 PC판입니다.

## 0.1.2 테스트판

- Windows 코드 서명이 없는 사전 검증판입니다. Windows에서 게시자를 확인할 수 없다는 안내가 표시될 수 있습니다.
- Windows 실기기에서 설치·실행·제거·재설치 확인이 필요합니다.
- 테스트 자동 업데이트가 연결되어 있습니다. 0.1.0·0.1.1에서는 처음 한 번 직접 설치해야 합니다.
- 기존 게임이 있다면 게임 내 백업을 만들고 정상 종료한 뒤 같은 위치에 설치하세요.
- 이후 새 패치를 자동 다운로드하고, 정상 종료 시 저장·백업을 마친 뒤 적용합니다.

## 처음 확인할 항목

새 테스트 커리어에서 하루 진행과 전술 변경 후 정상 종료해 보세요. 다시 실행했을 때 진행이 유지되는지 확인한 뒤 기존 웹 백업을 가져오는 것을 권장합니다.

경기 도중 정상 종료한 경우, 커리어를 불러와 일시정지 상태의 경기를 재개할 수 있습니다.
