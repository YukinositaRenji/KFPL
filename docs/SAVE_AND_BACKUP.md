# 저장·백업·복원

## PC 저장

진행 내용은 설정한 자동 저장 간격, 수동 저장, 정상 종료 시점에 PC에 저장합니다. 기본 저장 폴더는 다음과 같습니다.

```text
%APPDATA%\KFPL Football Manager 2026\saves
```

게임 상단의 **저장 폴더** 버튼으로 열 수 있습니다.

## 백업 내보내기

게임의 **환경설정 → 데이터 → 백업 다운로드**에서 저장할 경로를 선택합니다. 현재 커리어와 이전 시즌 경기 기록을 JSON 파일로 보관합니다.

게임이 실행 중일 때는 이 기능으로 백업해 주세요. 저장 폴더 전체를 직접 복사하려면 게임을 정상 종료한 뒤 복사합니다.

## 기존 웹 커리어 가져오기

1. 웹 게임에서 현재 진행을 저장합니다.
2. 환경설정의 데이터 화면에서 백업 파일을 내보냅니다.
3. PC 게임 상단의 **웹·PC 백업 가져오기**를 선택합니다.
4. 내보낸 JSON 파일을 선택합니다.
5. 커리어 목록에서 복원된 감독과 구단을 확인합니다.

복원은 별도의 커리어를 만듭니다. 웹과 PC 사이에서 이후 진행이 자동 동기화되지는 않습니다.

## 자동 백업

`saves/backups` 폴더에 보관합니다. 자동·종료·불러오기 전 백업은 커리어별 최근 10개를 유지하며, 삭제 전·업데이트 전 백업은 별도로 보관합니다.

자동 백업 JSON도 **웹·PC 백업 가져오기**로 복원할 수 있습니다. 백업을 다른 드라이브에 복사하면 PC 디스크 고장에 대비할 수 있습니다.

강제 종료·전원 차단 시 미저장 진행은 마지막 저장으로 돌아갈 수 있습니다. 저장 오류가 표시되면 현재 창을 유지하고 저장 상태를 확인해 주세요.
