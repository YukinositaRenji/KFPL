# 업데이트 안내

## 현재 상태

0.1.0 테스트판에는 자동 패치가 활성화되어 있지 않습니다. 배포 경로, Windows 서명, 실제 버전 간 업데이트 확인이 끝나면 지원 버전을 별도로 공지합니다.

## 자동 패치 지원 버전의 예정 동작

1. 게임 시작 후 새 버전을 확인합니다.
2. 업데이트가 있으면 플레이 중 백그라운드로 다운로드합니다.
3. 다운로드가 끝나면 준비 완료 안내를 표시합니다.
4. 게임을 정상 종료할 때 진행을 저장하고 커리어를 백업합니다.
5. 종료 후 업데이트를 설치합니다.

경기 중 자동으로 게임을 재시작하지 않습니다. 업데이트에 연결하지 못하면 현재 버전으로 계속 플레이할 수 있습니다. 저장·백업에 실패하면 종료 전 오류를 알려줍니다.

## 수동 업데이트

릴리스 공지를 읽고 기존 커리어를 백업한 뒤 게임을 정상 종료하세요. 새 설치 프로그램을 실행하고, 업데이트 후 기존 커리어가 보이는지 확인해 주세요.

Windows 실기기 검증이 끝나지 않은 버전은 테스트판으로 구분합니다. 각 버전의 알려진 제한과 세이브 호환 여부는 릴리스 공지를 기준으로 확인해 주세요.
