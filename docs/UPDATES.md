# 업데이트 안내

## 0.1.2부터 테스트 자동 업데이트 지원

[PC 테스트 배포](https://github.com/YukinositaRenji/KFPL/releases/tag/pc-test)에 게시된 새 테스트 버전을 받습니다. 정식 배포와 분리된 테스트 채널이며 Windows 배포자 서명은 검증하지 않습니다. HTTPS와 설치파일 무결성 검사는 유지합니다.

0.1.0·0.1.1은 자동 업데이트 주소가 없으므로 0.1.2 설치파일을 한 번 직접 설치해야 합니다. 기존 진행을 백업하고 게임을 정상 종료한 뒤 같은 위치에 설치하세요.

## 자동 업데이트 동작

1. 시작 10초 후, 이후 실행 중 6시간마다 새 버전을 확인합니다. 도구 모음의 수동 확인도 가능합니다.
2. 새 버전이 있으면 플레이 중 백그라운드에서 다운로드합니다.
3. 다운로드가 끝나면 준비 완료 안내를 표시합니다.
4. 정상 종료 시 진행을 저장하고 전체 커리어를 백업합니다.
5. 저장·백업이 성공하면 종료 후 설치합니다. 다음 실행부터 새 버전을 사용합니다.

경기 중 강제로 재시작하지 않습니다. 다운로드에 실패하면 현재 버전으로 계속 플레이할 수 있습니다. 저장·백업에 실패하면 설치와 종료를 중단합니다.

개발자가 더 높은 버전의 패치를 게시한 뒤 자동으로 받을 수 있습니다. 0.1.2 설치 직후에는 같은 버전을 다시 설치하지 않습니다.

## 직접 설치가 필요한 경우

릴리스 공지를 읽고 기존 커리어를 백업한 뒤 게임을 정상 종료하세요. 새 설치 프로그램을 실행하고, 업데이트 후 기존 커리어가 보이는지 확인해 주세요.

이 테스트판의 실제 Windows 버전 간 자동 교체는 추가 확인이 필요합니다. Windows가 실행 경고를 표시할 수 있으며, 보안 프로그램을 끄지 마세요.
